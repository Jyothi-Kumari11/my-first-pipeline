# \# Hello World CI Pipeline

# 

# A beginner GitHub Actions capstone project.

# 

# \## Files

# \- `hello.sh` — Prints Hello, world!

# \- `.github/workflows/ci.yaml` — Defines the CI workflow.

# 

# \## Workflow

# The pipeline runs when a pull request targets the `main` branch.

# 

# Jobs run in sequence:

# 1\. Build

# 2\. Test

# 3\. Deploy

# 

# \## Run locally

# ```bash

# bash hello.sh

# ```
